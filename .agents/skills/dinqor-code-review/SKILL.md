# dinqor-code-review

先确定 diff、调用者和现有检查；优先定位数据丢失、权限、异步竞态、重复写入、生命周期和无障碍问题。结论给触发条件、后果、代码位置和验证证据，未确认的风险不要表述成已发生缺陷。

UI 审查读取布局与组件治理 skills，检查低高度与窄屏、长标题、弹框内部滚动、底部操作、loading、提交锁和搜索结果顺序。布局结论尽量用真实渲染核对，测试或构建通过不能替代浏览器观察。

语言、API 和模块边界按各自 skill。检查测试是否覆盖真实行为及失败路径，不弱化断言来通过；区别既有失败与本次回归。

只读审查不自动授权提交、推送或发布。报告具体范围与未验证项，不使用“所有页面均无问题”一类无依据结论。
