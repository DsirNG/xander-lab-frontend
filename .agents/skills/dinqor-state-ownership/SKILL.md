# dinqor-state-ownership

局部状态归组件，同页面协调归页面或模块 hooks，跨页面使用已有会话、偏好或上下文能力。不要为了单页交互引入新的状态库。

派生值从来源计算，避免复制服务端对象或双份数组。useMemo/useCallback 用于稳定昂贵计算和实际依赖，不为所有函数添加缓存。useRef 可持有请求版本、同步锁和最新回调，不在渲染期产生网络副作用。

定时器、事件监听、AbortController、SSE、轮询在 effect 清理时释放；组件/会话切换后旧结果不得写入新会话。语言和主题切换原地更新，不能因翻译函数引用改变重建正在运行的业务流。

失败保留有效输入；区分请求 pending、服务端运行状态与取消请求状态。取消操作要等待服务端状态或流事件确认，不能只断开页面 SSE 就宣称任务已停止。
